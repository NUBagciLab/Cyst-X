Model inputs for reader comparisons used radiologist-defined pancreas regions of interest to isolate classification performance from automated segmentation errors. \textcolor{red}{Values outside parentheses use prespecified thresholds determined exclusively from training data}; parenthetical values use a 0.50 probability threshold.
